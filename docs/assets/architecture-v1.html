这张图必须守住的约束（选错选型也不能违反）

AR2 / AR5 正本唯一：适配器不得持有唯一副本；对话在会话账、业务在 ops.sqlite、记忆在 memory/。
AR10 / AR11 双闸取严：域/目录为主，动作风险只上调；审批正本在库里，卡片只是视图。
AR12 入口归一：任何客户端消息都必须经网关，不能从适配器直通执行。
AR15 无审计即未完成：动作与证据同事务落库，链断则停写。
AR23 / AR25 单一写者 + 唯一 dispatcher：跨模块只经 API 或事件，禁直读表。
AR27 / AR30 渠道不做业务；子代理权限 = 父 ∩ 任务范围，父撤销即失效。
AR31 / AR32 工具可换、闸不可绕；ports/ 内零协议名 / 命令名 / 产品名。
AR34 专家无治理权：无自有审批、无自有凭据、不得出 A 域、事件必须回传。
读图顺序：外部 → 客户端 → 渠道 → ① 网关 → 内核 7 模块（含 Agent 侧）→ 端口 → 适配器 → 底座；右侧是数据面。 只有一条主线：消息进 → 判断 → 排期 → 执行 → 结果出；任何绕开内核的旁路都是架构违规。
