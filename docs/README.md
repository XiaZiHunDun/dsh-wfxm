## 四、复核纪律

01–08 由前一阶段的分析产出，09 已对其逐条回源码复核。**引用 01–08 的结论做判断前，先看 09 §六 是否已推翻它。**

已知被推翻/修正的重点：

1. **V2 并发写**：dsh **有** `withFileLock` 跨进程锁原语，之前判"完全没有"是错的。
2. **引用路径**：dsh 是 `<domain>/<pkg>/` 双层目录，02/06 的多数 `packages/xxx/src/...` 少一层。
3. **规模数字**：WFXM 含测试 625 文件 / 87,273 行；不含测试 304 文件 / 42,276 行。
4. **iLink**：可复用的是**非测试 1,228 行**（含测试 1,920 行）。
5. **acceptance 场景库**：58 个 fixture **确实存在**；但可执行测试只有 `realistic.test.ts` 的 3 个用例，且深度绑定 `runButlerLoop`。
