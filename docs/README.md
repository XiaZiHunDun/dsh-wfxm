## 四、复核纪律

01–08 是早期分析产出，09 已逐条回源码复核。**引用 01–08 的结论做判断前，先看 [09 §六](09-能力对照与实现路径.md) 是否已推翻它。**

已被推翻或修正的重点：

1. **V2 并发写**：dsh **有** `withFileLock`，早期"完全没有"是错的。
2. **引用路径**：`<domain>/<pkg>/` 双层，早期文档（01–06）的多数路径少一层。
3. **规模与 iLink 口径**：WFXM 含测试 625 文件 / 87,273 行；iLink 可复用非测试 1,228 行。
4. **acceptance 场景库**：58 个 fixture 存在，但可执行为 `realistic.test.ts` 的 3 个用例。
