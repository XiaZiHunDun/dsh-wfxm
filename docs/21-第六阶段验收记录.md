演练断言（任务级失败）：

1. 失败回执 ≤4 行，含阶段、错误码、`追踪：<traceId>`；
2. `/diag` 在 3s 内给出阶段/原因/追踪；
3. `scripts/trace.mjs export` 含停止点（`turn_end` 或 `phase:error`）；
4. attempt 行 `errorCode` 与 `traceId` 均非空。

基础设施故障（1/4/5）按设计不产生任务失败，验收为 fail-open + 可计量。
