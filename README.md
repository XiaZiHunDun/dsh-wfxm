# dsh-wfxm — 基于 DeepSeek Harness 的迁移工作区

> **状态**：规划阶段，尚无代码
> **建立日期**：2026-10-15
> **本目录性质**：分析与规划工作区。后续基于 dsh 的开发在此进行。

## 一句话

WFXM（Butler v5）的微信渠道与治理资产，迁移到 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）之上。

---

## 决策摘要

**做**：dsh 当执行引擎，微信渠道直接用社区插件 `xmanrui/dsh-im`，Butler 的治理与中文产品语义写成 dsh 插件。
**不做**：fork dsh 或 dsh-im；不做 sidecar 过渡；不重写 iLink 协议层（除非将来决定改微信体验）。
